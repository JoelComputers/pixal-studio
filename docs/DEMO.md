# Dragon demonstration

[Watch the video](https://joelcomputers.github.io/pixal-studio/#demo-title) ·
[Download MP4](https://joelcomputers.github.io/pixal-studio/media/dragon-demo.mp4)

This silent, approximately 28-second video has on-screen captions:

- **0–4 seconds:** "Give your image shape. Start with one reference."
  The image is the locally generated SDXL forest dragon reference.
- **4–18 seconds:** "A model. Every angle. Orbit it. Inspect it. Take it into
  your workflow." The original Pixal Studio GLB makes a full turn in Three.js.
  "Detailed preset · 4K textures · No manual mesh or texture repair."
  The footer states: "Generation skipped · This run: 206 sec + queue time."
- **18–23 seconds:** A real screenshot of the local app displaying the dragon.
  "Upload → Generate → Download GLB. Runs through your existing ComfyUI queue."
- **23–28 seconds:** "Turn it around yourself." The gallery address appears,
  followed by "Free developer preview · Existing ComfyUI required."

The demo is a composed presentation of a real reference, exported GLB, and
application screenshot. It is not an uninterrupted screen recording of a new
generation. The turntable changes only the viewing camera, not the geometry or
textures. It uses the same Three.js lighting as the interactive gallery.

Model generation took 206.2 seconds excluding queue time. This is one observed
run, not a performance guarantee. [Full settings and hashes](provenance.json).
